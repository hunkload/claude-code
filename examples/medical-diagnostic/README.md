# HELIX-MERIDIAN Diagnostic Suite

A self-contained, interactive sci-fi medical diagnostic display. It is a single
HTML file with no dependencies, so you open `index.html` in any modern browser.
All patient data is fictional.

## What you can do

- **Inspect organs.** Click any organ on the hologram (brain, lungs, heart,
  liver, stomach, kidneys, intestines, uterus and ovaries, skeleton) to get live
  telemetry, a 30-second trend line and clinical notes.
- **Target with the reticle.** Drag the centre handle, click empty space or use
  the arrow keys. The optical-zoom monitor and the CT-style **axial slice**
  update in real time for the level you are aiming at.
- **Toggle layers.** Dermal, Skeletal, Organs, Vascular and Neural (keys `1`–`5`).
- **Run a full body scan** (`S`). A tomographic beam sweeps the body, logs each
  organ it checks and may flag anomalies. Select a flagged region and deploy
  the nanite repair swarm to clear it.
- **Override life support.** Heart and breathing sliders drive the ECG, the
  respiration wave, lung and heart animation, SpO₂, blood pressure and the
  neural monitor. Push them out of range to set off alarms, or use
  **Alarm Bypass** (`B`).
- **Change the display mode** (`M`). Choose **Holo** (glass hologram),
  **X-Ray** (light-box blue) or **CRT-84** (retro vector terminal with
  scanlines).
- Optional sound (beeps and alarms) is off by default. Press `?` for help.
